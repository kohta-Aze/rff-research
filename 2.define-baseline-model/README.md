## 入力・分割

- ManyRx compactの抽出済みプレアンブル256点のI/Q。NPZの`iq`は`float32[N,256,2]`、保存時は未正規化、読込時に信号単位RMS、DC除去なし。
- equalizedを使用。unprocessedと同じ配列番号でも同一信号とは限らない。信号番号はNPZの添字で、元パケットID・時刻ではない。
- 10 Tx×32 Rx×4日。equalizedは空23組・247,684信号。空組はスキップし、0や未知信号で補完しない。
- 主評価は全日・全Txで200信号がそろう同じ16 Rx。Txは既知6／調整用未知2／評価用未知2。具体的IDは共通設定と`fold_XX.json`を参照。

| view | 収録日 | 1 Tx×Rxの信号数 | 全体件数 |
|---|---|---:|---:|
| train・既知のみ | 2021-03-01 | 120 | 11,520 |
| validation_known | 2021-03-01 | 40 | 3,840 |
| validation_unknown・調整専用Tx | 2021-03-01 | 40 | 1,280 |
| test・既知＋評価専用未知Tx | 03/01・03/08・03/15・03/23 | 各日40 | 各日5,120 |

- SHA-256順位・split seed 42で役割と信号を固定。5 foldを定義し、実験済みはfold 0・学習seed 42。各Txの役割は5 fold中で既知3回・調整未知1回・評価未知1回。
- 学習・validation・同日testは信号番号が重ならない。未知評価Txは学習・校正・validationへ入れない。testでモデル・しきい値を選び直さない。
- 全32 Rxの補助評価は主評価と参照が重なる。受信機分離評価とは区別し、独立標本として合算しない。設定の`draft_for_review`は人のレビュー未完了を表す。

## モデル・判定規則

- 入力`[B,2,256]`、Conv1d 32→64→128、kernel 7／5／3、BN・ReLU・MaxPool、128次元特徴、dropout 0.2、既知6クラス。
- 新規学習: Adam、lr 0.001、batch 64、上限50 epoch、patience 10。MSP・SupCon・MTPLは同じseedの初期encoderから学習。Cosine・OpenMaxはMSPの同じCNNを固定。
- MSP・MTPLは既知validationの分類CE最小、SupConはtraining Prototypeに対する既知validation CE最小でcheckpointを選択。lossだけの因果比較や同一計算予算の比較ではない。
- Cosineはtrainingの生特徴をクラス別平均後にL2正規化。Improved Prototype Learningの追加正則化は未実装。
- SupConは独立2 view、温度0.07、位相±10度・AWGN 30 dB・RMS。推論は投影前特徴。MTPLは`CE + 0.1×復元二乗誤差総和 + 0.05×正解Prototype二乗距離`、全trainingの0.9分位超過をGPD fit。詳細値は各固定設定が正本。
- OpenMaxは正解した既知trainingの6次元logitsを使用。距離`Euclidean/200 + cosine`、libMRのWeibull、tail 20／50／100×alpha 1／3／6。
- validationで`(CCR + 1 − FAR)/2`を最大化。OpenMax候補の同点は設定順、しきい値の同点は高い正値を選ぶ。未知確率が既知最大確率以上なら拒否、それ以外は既知最大確率としきい値を比較。
- OpenMaxの順位スコアは既知勝者なら最大既知確率、未知勝者なら負の未知確率。AUROC・OSCRは負領域も掃引し、運用では使わない受入領域も含む。面積と固定しきい値のCCR・FARを区別する。
- MTPLのGPDスコアは既知の事後確率ではない。固定delta 0.01と負の距離は補助評価で、validationで選んだ主評価と置き換えない。

## 実行

- リポジトリ直下のPowerShellで実行。確認環境はWindows・Python 3.13.14・CPU 4スレッド。依存版はrequirementsと結果JSONの`runtime`を参照。
- 環境がない場合はPython 3.13で作成し、依存を導入する。libMRのビルドにはC++コンパイラが必要。

```powershell
$base = '2.define-baseline-model'
$prep = "$base/00_common/data_preprocessing"
# venvがない場合だけ実行
python -m venv "$prep/venv"
$python = "$prep/venv/Scripts/python.exe"
& $python -m pip install -r "$base/00_common/modeling/requirements.txt"
& $python -m pip install Cython==3.1.3
& $python -m pip install libmr==0.1.9 --no-build-isolation
```

- 元データを`$prep/data/ManyRx.pkl`へ配置し、未準備の場合だけ次を順に実行する。既存データを使う場合は再生成不要。

```powershell
& $python "$prep/scripts/01_inspect_wisig.py" --input "$prep/data/ManyRx.pkl" --output "$prep/output/inspection.json"
& $python "$prep/scripts/02_prepare_wisig.py" --input "$prep/data/ManyRx.pkl" --output-root "$prep/output/prepared-wisig" --representation equalized --dtype float32
& $python "$prep/scripts/03_profile_coverage.py" --prepared-root "$prep/output/prepared-wisig" --output-root "$prep/output/coverage"
& $python "$prep/scripts/04_build_splits.py" --prepared-root "$prep/output/prepared-wisig" --config "$prep/configs/day_shift_draft.json" --output-root "$prep/output/splits/day_shift_draft"
& $python "$prep/scripts/05_verify_data.py" --prepared-root "$prep/output/prepared-wisig" --splits-root "$prep/output/splits/day_shift_draft" --source "$prep/data/ManyRx.pkl" --output "$prep/output/data_readiness.json"
```

- `data_readiness.json`の`verification_passed: true`を確認する。`prepared-wisig/`は波形・manifest・元データhash、`splits/`は役割・信号番号・配分の記録。欠測・hash不一致・分割重複は停止する。
- 初回5手法を再実行する場合は下記。採用モデルだけならMSP→Cosine→OpenMaxまで。CosineはOpenMax実行時の比較表に必要。`$name`は存在しない出力名へ変える。

```powershell
$name = 'reproduction_fold00_seed42'
$msp = "$base/01_cnn_msp/output/$name"
$cosine = "$base/02_cnn_cosine_prototype/output/$name"
$openmax = "$base/03_cnn_openmax/output/$name"
$supcon = "$base/04_supcon_prototype/output/$name"
$mtpl = "$base/05_mtpl_evt/output/$name"
& $python "$base/01_cnn_msp/scripts/run_experiment.py" --fold 0 --seed 42 --output $msp
& $python "$base/02_cnn_cosine_prototype/scripts/run_prototype_experiment.py" --source-run $msp --output $cosine
& $python "$base/03_cnn_openmax/scripts/run_openmax_experiment.py" --source-run $msp --prototype-run $cosine --output $openmax
& $python "$base/04_supcon_prototype/scripts/run_supcon_experiment.py" --reference-run $msp --prototype-run $cosine --openmax-run $openmax --output $supcon
& $python "$base/05_mtpl_evt/scripts/run_mtpl_experiment.py" --reference-run $msp --prototype-run $cosine --openmax-run $openmax --supcon-run $supcon --output $mtpl
```

## モデルからの読込

```python
from pathlib import Path
import sys

sys.path.insert(0, str(Path("scripts").resolve()))
from wisig_dataset import WisigDataset

dataset = WisigDataset(
    "output/prepared-wisig",
    "output/splits/day_shift_draft/fold_00.json",
    "train",
)
iq, label, metadata = dataset[0]
for iq_batch, labels, metadata_batch in dataset.iter_batches(64):
    break
```

- 1件: `float32[256,2]`、ラベル、Tx・Rx・日付・信号番号などのメタデータ
- バッチ: `float32[B,256,2]`、`int64[B]`、メタデータ一覧
- CNNの `[B,2,256]` やPyTorchテンソルへの変換はモデル側で実施
- 既知ラベル: 各foldの `class_map`、0〜5。未知ラベル: `-1`、通常の分類損失へ入れない
- `sample_rms`: 各信号を `sqrt(mean(I²+Q²))` で割る。I/Q比・位相を維持、DC除去なし
- 信号自身だけで正規化。ゼロ電力・非有限値は停止。振幅尺度が必要な別条件は `none` を使用
- NPZ読込時にハッシュ・形・型・有限値を照合。戻り値の変更は保存波形に影響しない
- `cache_groups=64`: 最大64グループを保持。`iter_batches(64, shuffle_seed=0)` で再現可能なシャッフル
- 学習用データはNPZの直接列挙で作らず、共通分割のview・信号番号を使用

| view | 用途 |
|---|---|
| `train` | 既知Txの分類学習 |
| `validation_known` | モデル選択・しきい値調整の既知信号 |
| `validation_unknown` | 調整専用の未知信号。分類学習へ入れない |
| `test_2021_03_01` など | 16 Rxの主評価、既知＋評価専用未知Tx |
| `supplemental_test_2021_03_01` など | 全32 Rx、各組最大40件。欠測・少数組を保持 |
| `paired_supplemental_test_2021_03_01` など | 全評価日の共通Tx×Rxを各日同件数で比較 |

- 空組から架空のサンプルを返さない。3種類のtestは重複する参照で、独立集合として結合しない

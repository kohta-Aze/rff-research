## 比較の中心

5手法へ同じ入力を渡し、同じ条件で比較

## 固定が必要な項目

| 項目 | 決める理由 |
|---|---|
| 表現を equalized / unprocessed のどちらにするか | 入力そのものが変わるため |
| 既知端末と未知端末 | Open-Set の難しさが変わるため |
| 学習用の受信機と評価用の受信機 | 受信機を覚える問題を調べるため |
| 学習日と評価日 | 日が変わったときの精度低下を測るため |
| 1グループの最大信号数 | データ量を公平にするため |
| CNN 骨格 | 未知判定方法だけの差を見やすくするため |
| seed と繰り返し回数 | たまたま良い結果を避けるため |

## 評価指標の候補

- **Known accuracy**: 既知端末を正しい端末名へ分類できた割合
- **AUROC**: しきい値を動かしたとき、既知と未知を分ける総合力
- **FPR95**: 未知の95%を見つける設定で、既知を誤って未知にした割合
- **OSCR**: 既知端末の正しい分類と未知端末の拒否を一緒に見る曲線
- **Macro F1**: 端末ごとの偏りを抑えた分類指標

## 評価の段階案

1. 同じ日・同じ受信機で基本動作を確認する。
2. 日だけを変え、時間変化への弱さを見る。
3. 受信機だけを変え、受信機依存を見る。
4. 日と受信機の両方を変え、最も厳しい条件を見る。

最終的な第一ベースラインは、単一の最高値だけでなく、条件変化での低下量と複数 seed のばらつきも見て決めます。

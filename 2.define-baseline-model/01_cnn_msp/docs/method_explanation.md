# CNN + MSP のやさしい説明

## 何をする方法か

CNN は I/Q 信号を読み、既知端末ごとに点数を出します。Softmax はその点数を、合計が1になる確率らしい値へ変えます。MSP は **Maximum Softmax Probability** の略で、その中の最大値です。

たとえば3台の既知端末に対して `[0.90, 0.07, 0.03]` なら MSP は `0.90` です。`[0.38, 0.34, 0.28]` なら MSP は `0.38` です。後者は自信が低そうなので、しきい値より小さければ未知とします。

## 何を目的にするか

一番簡単な Open-Set 基準を作ることです。複雑な手法が MSP より良くなければ、その複雑さを追加する意味が小さいと判断できます。

## 学習時の入力と出力

- 入力: 既知端末の I/Q 信号
- 正解: どの既知端末から送られたか
- 出力: 既知端末ごとの logits
- 損失: cross entropy

未知端末の信号は、基本の分類学習へ入れません。

## 評価時の入力と出力

1. I/Q 信号を CNN へ入れる。
2. logits を Softmax へ入れる。
3. 最大値 MSP を取り出す。
4. MSP がしきい値以上なら、その端末 ID を出す。
5. MSP がしきい値未満なら `unknown` を出す。

## しきい値の決め方

最終評価データでは決めません。学習とは別の validation データで候補を比較し、決めた値を固定してから test を一度だけ評価します。

## 限界

ニューラルネットは、見たことのない信号にも高い Softmax 値を出すことがあります。Softmax は既知クラスの中でどれが一番近いかを表す仕組みで、未知である確率を直接学んでいないためです。

# CNN + OpenMax のやさしい説明

## 何をする方法か

まず既知端末だけで CNN を学習します。次に、正しく分類できた既知信号の activation vector を端末ごとに集め、平均ベクトルを作ります。

平均から特に遠い既知信号だけを集め、その「遠さの端の部分」を Weibull 分布で表します。新しい信号が中心から極端に遠ければ、元の既知クラスの点数を減らし、その分を unknown へ移します。

## たとえ

クラスの中心を学校、既知信号を生徒の家だとします。普段どこまで遠くに住む生徒がいるかを調べます。新しい家が、これまでの一番遠い地域よりさらに不自然に遠ければ、その学校の生徒ではない可能性が高いと考えます。

## calibration の入力と出力

- 入力: 学習済み CNN、正しく分類された既知信号の activation vector
- 処理: クラスごとの平均を計算し、遠い距離の上位 tail を Weibull へ当てはめる
- 出力: クラスごとの平均 activation と Weibull の shape・scale など

## 推論の入力と出力

1. 新しい信号の activation vector を作る。
2. 点数上位のクラスについて中心からの距離を測る。
3. Weibull モデルで、その距離が外れ側か計算する。
4. 既知クラスの activation を減らし、unknown 用 activation へ移す。
5. OpenMax 確率を計算し、しきい値と合わせて判定する。

## 調整が必要な値

- tail size: 遠い既知信号を何件使うか
- alpha rank: 点数上位の何クラスを補正するか
- distance: Euclidean、cosine、または組み合わせ
- unknown 判定しきい値

これらは validation データだけで決め、test では変えません。

## 限界

保存した原論文は画像分類で評価されています。RFF では特徴分布が受信機や日に強く動くため、Weibull の tail が端末差ではなく環境差を表す可能性があります。また、tail size などの選び方で結果が変わります。

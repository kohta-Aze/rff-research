# 複数日学習・OpenMax再校正の初回実験

- **主結果:** 学習総数を11,520信号にそろえた2日学習は、03/23のOSCRが1日学習の0.491から0.570へ上昇。3日学習は0.475で、日数を増やすだけでは改善しなかった。
- 同じfold 0・seed 42。CNN＋OpenMax、既知6 Tx・Rx16台。各条件でCNNを学習し、同じvalidation数でOpenMaxの候補・しきい値を選んだ。信号をTx・Rx・日単位で照合し、全条件で学習／validation／評価の重複がないことを確認した。

- **解釈:** 2日条件では、既知受入率の上昇より未知の誤受入率低下が大きく、今回のOSCR改善を支えた。3日条件では誤受入率が悪化した。データ多様性、日ごとの信号数、validation配分のどれが差を生んだかは、この1回の実験では特定できない。
